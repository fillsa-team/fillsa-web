## [배경 테마 섹션]

- 목적: 앱의 10가지 배경 테마를 시각적으로 소개하여 개성화 가치 전달
- 진입 경로: 히어로 스크롤 다운 / 네비 "테마" 링크 클릭
- 구성요소:
  - [섹션 헤더] eyebrow: "배경 테마" / 타이틀: "오늘의 감성으로 나만의 필사 카드를" / 설명: "밝은 파스텔부터 깊은 다크 테마까지, 기분에 맞는 배경을 골라보세요."
  - [테마 카드 트랙] 10종 카드 무한 가로 스크롤:
    1. 라벤더 퍼플
    2. 오션 블루
    3. 네이처 그린
    4. 오렌지
    5. 크림/황금
    6. 로즈/핑크
    7. 민트
    8. 다크
    9. 딥 퍼플
    10. 블랙
  - 각 카드: 예시 문장 텍스트 + 하단 그라디언트 오버레이 표시
- 인터랙션:
  - CSS 애니메이션으로 좌측 무한 스크롤 (22초 주기)
  - hover 시 애니메이션 정지
  - 개별 카드 hover 시 위로 4px 이동
- 예외/엣지케이스:
  - 클릭 이벤트 없음 (소개용 전시 목적)

- 진입 경로: 테마 섹션 스크롤 다운 / 네비 "새로운 기능" 링크 클릭
- 구성요소:
  - [섹션 헤더] eyebrow: "리뉴얼 신기능" / 타이틀: "단순한 필사를 넘어 깊은 사유로 NEW" / 설명: "AI와 함께 문장을 더 깊이 이해하고, 나만의 생각을 발견하세요."
  - [기능 카드 1 — AI 질문 & 성찰 일지 🤔] wide 카드 (전체 너비) / 인터랙션 데모 포함 (아래 섹션 참조)
  - [기능 카드 2 — 문장 발견 ✨] 설명: "나의 취향과 필사 패턴을 분석해 오늘 필사하고 싶은 문장을 추천해 드립니다."
  - [기능 카드 3 — 필사 인사이트 📊] 설명: "자주 필사하는 주제, 작가, 감정의 흐름을 시각화해 나만의 취향을 발견하세요."
  - [기능 카드 4 — 감성 카드 공유 🎴] 설명: "필사한 문장을 아름다운 카드 이미지로 만들어 SNS에 공유해 보세요."
- 예외/엣지케이스:
  - 카드 2~4는 소개용 텍스트만 표시, 별도 상세 링크 없음
  - wide 카드는 모바일에서 1열로 전환

## [AI 질문 & 성찰 일지 인터랙션 데모]

- 목적: AI 성찰 일지 기능의 사용 흐름을 인터랙티브하게 체험
- 진입 경로: 신기능 섹션 내 첫 번째 카드
- 구성요소:
  - [왼쪽 패널]
    - 기능 설명 텍스트
    - 문장 선택 chip 3개 (클릭 가능):
      - 파울로 코엘료: "모든 사람은 자신의 우주를..."
      - 헤르만 헤세: "두려움이 있는 곳에 꿈이..."
      - 법정 스님: "지금 이 순간은 다시 오지..."
  - [오른쪽 패널 — AI 채팅 창]
    - 채팅 헤더: "AI 성찰 도우미" + 상태 표시 (입력 중… / 응답 완료 / 기록됨 ✓)
    - 필사 문장 인용 블록
    - AI 질문 버블 (타이핑 애니메이션, 30ms/글자)
    - 답변 제안 chip 3개 (이모지 + 답변 텍스트)
    - 사용자 답변 버블
    - 텍스트 입력 필드 + 전송 버튼
- 인터랙션:
  - 문장 chip 클릭 → 인용 블록 변경 + AI 질문 타이핑 재생
  - 타이핑 완료 → 제안 chip 페이드 인
  - 제안 chip 클릭 → 입력 필드 자동 입력 → 전송
  - Enter 키 또는 전송 버튼 → 답변 버블 표시, 상태 "기록됨 ✓"
  - 새 문장 chip 클릭 시 이전 답변/상태 초기화
- 예외/엣지케이스:
  - AI 타이핑 중 다른 chip 클릭 무시 (isTyping guard)
  - 빈 입력 상태에서 전송 버튼 클릭 무시
  - 전송 후 전송 버튼 비활성화 (중복 제출 방지)

## [사용법 섹션]

- 목적: 3단계 사용 플로우를 스크린샷과 함께 설명하여 진입 장벽 낮추기
- 진입 경로: 신기능 섹션 스크롤 다운 / 네비 "사용법" 링크 클릭
- 구성요소:
  - [섹션 헤더] eyebrow: "사용법" / 타이틀: "3단계로 시작하는 나만의 필사 습관"
  - [Step 1 — 문장을 고르세요] 번호: ①
    - 설명: "마음에 드는 문장을 직접 입력하거나, 오늘의 추천 문장 중에서 선택하세요. 배경 이미지도 함께 업로드할 수 있어요."
    - 레이아웃: 스크린샷 왼쪽, 텍스트 오른쪽
  - [Step 2 — 직접 써보세요] 번호: ②
    - 설명: "원하는 영역을 선택하고 타이핑하세요. 필사한 항목은 메모 화면으로 이동해 더 깊이 기록할 수 있어요."
    - 레이아웃: 텍스트 왼쪽, 스크린샷 오른쪽 (역방향)
  - [Step 3 — 기록을 쌓아가세요] 번호: ③
    - 설명: "캘린더에서 날짜별 필사 기록을 확인하고, 명언 리스트로 이동해 쌓인 문장들을 다시 돌아보세요."
    - 레이아웃: 스크린샷 왼쪽, 텍스트 오른쪽
- 인터랙션:
  - fade-up 스크롤 애니메이션
- 예외/엣지케이스:
  - 모바일에서 1열 레이아웃으로 전환 (스크린샷 → 텍스트 순)
  - 스크린샷은 실제 앱 이미지 파일 필요
